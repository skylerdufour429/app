# App Collection

GitHub Pages + Codespaces compatible iOS app archive catalog.

## Features

- Search apps
- iOS metadata display
- Bundle ID listing
- Version information
- IPA download placeholders
- PWA support

## Run locally

Open:

index.html


## GitHub Pages

Repository:

Settings
→ Pages
→ Deploy from main branch


## Codespaces

Open:

Code
→ Codespaces
→ Create
